# @MalenkyiVsesvitBot

Два незалежні модулі в одному боті (один токен - один процес polling):

1. **Прикорм** - щоденник харчування дитини, бібліотека продуктів, тарілки, рецепти,
   реакції, зростання за ВООЗ, нагадування. Модуль `feed/`, контент у `data/`.
2. **YouTube downloader** - кинь посилання, обери якість, отримай файл. `/yt`.


## Прикорм

`/start` - головне меню. Керування кнопками.

| 🧊 Холодильник | Що є вдома. Складає тарілки тільки з наявного і рахує **закупівлю на тиждень уперед**. Продукти додаються тапом або одним рядком «морква, гречка, індичка» |
| 🥕 Продукти | 202 картки: з якого віку, алерген, ризик подавитися, **як подавати саме зараз** за віком дитини, користь, застереження. Позначки ✅ 🆕 👀 ⛔ ⏳, алерген позначено ❗ |

### Полиці білка

Мʼясо, риба, яйця і бобові лежать на окремих полицях (`sub:` у `products.yaml`),
бо шукати індичку серед сорока шести позицій незручно. Для балансу тарілки це
один слот: `group` лишається `protein`, і генератор рахує їх разом.

### Генератор тарілок

`feed/suggest.py`. Тарілка вважається зібраною, коли закриті чотири слоти:
рослинне, вуглевод, білок, жир.

- **🎲 Ще варіанти** - нові комбінації з продуктів, дозволених за віком і не
  позначених «уникаємо». Знайоме важить утричі більше за нове, і в одній тарілці
  максимум один ще не введений продукт.
- **✍️ У мене вже є…** - пишеш «морква і курка», бот розпізнає продукти в тексті
  і добирає решту. Працює і без кнопки: будь-який текст із назвами продуктів
  веде в добір.

Розпізнавання - основа слова плюс словник синонімів (`ALIASES`): «картошка»,
«омлет», «сьомга», «творог», «паста» знаходяться. Спершу перевіряється пара
сусідніх слів («зелена сочевиця», «твердий сир»), потім точний збіг одного слова
по всьому каталогу, і лише потім збіг за початком. Стиль страви (`style:` у
`products.yaml`: main / breakfast / both) не дає зліпити лосося з грушею.
Картопля і батат закривають слот вуглеводу замість рослинного, інакше генератор
видає картоплю з макаронами. Цибуля і часник з генерації виключені - це приправа.
Продукти з `plate: false` (ковбаса, солодощі, снеки, чіпси) не потрапляють ні в
згенеровану тарілку, ні в список покупок: записати з'їдене вручну можна, радити - ні.

### Холодильник

Запас родини (`pantry` у базі, спільний для обох дорослих):

- **🍲 Скласти тарілку з цього** - той самий генератор, обмежений наявним удома.
  Слот, під який нічого немає, лишається порожнім, і бот каже, чого бракує.
- **🛒 Список покупок на тиждень** - `suggest.shopping()`. Тижнева норма:
  6 різних рослинних, 3 вуглеводи, 4 білки, 2 жири, а всередині білка ще й
  різноманіття (2 мʼясо, 1 риба, 1 яйця, 1 бобові). Віднімає те, що вже вдома,
  спершу пропонує те, що дитина вже їсть, і додає один новий продукт та один
  ще не введений алерген.
- **✍️ Списком** - до 20 продуктів одним повідомленням через кому.
- Продукт, що лежить понад тиждень, підсвічується кількістю днів.

### Спільний профіль

Один профіль дитини на кількох дорослих. Перший створює профіль, далі
**Налаштування → Додати дорослого** видає одноразовий код. Другий відкриває бота,
тисне «У мене є код запрошення», надсилає код - і пише в той самий щоденник.

Якщо `ALLOWED_USERS` заповнений, **створити нову родину** можуть тільки ці user_id,
а приєднатися за кодом - будь-хто, кого запросили. Свій id: `/id`.

## Керування

```bash
systemctl --user status ytbot          # стан
systemctl --user restart ytbot         # рестарт після правок bot.py
journalctl --user -u ytbot -f          # логи наживо
```

Автостарт увімкнено (`enable`), `Restart=always`, linger=yes → переживає і краш, і ребут.

## Налаштування — `~/ytbot/.env`

| Змінна | Що робить |
|---|---|
| `BOT_TOKEN` | токен бота |
| `LOCAL_API_URL` | порожньо = хмарний API (50 МБ); `http://127.0.0.1:8081` = локальний (2000 МБ) |
| `MAX_UPLOAD_MB` | ліміт віддачі: 50 для хмарного, 2000 для локального |
| `MAX_DURATION_MIN` | відсікає задовгі відео (типово 180) |
| `MAX_PARALLEL` | скільки завантажень одночасно (2 ядра → 2) |
| `ALLOWED_USERS` | порожньо = бот відкритий усім; список user_id = whitelist |
| `COOKIES_FILE` | шлях до cookies.txt, якщо YouTube почне вимагати логін |

## Ліміт 50 МБ → 2 ГБ

Хмарний Bot API не віддає файли більші за 50 МБ. Знімається локальним
`telegram-bot-api`. Що треба:

1. `sudo apt install -y cmake libssl-dev zlib1g-dev gperf`
2. `api_id` + `api_hash` з https://my.telegram.org → вписати в `~/ytbot/local-api.env`
3. `nohup ~/ytbot/setup-local-api.sh > ~/ytbot/build.log 2>&1 &` (збірка ~1.5-3 год на 2 ядрах)
4. `systemctl --user enable --now telegram-bot-api`
5. У `.env`: `LOCAL_API_URL=http://127.0.0.1:8081` і `MAX_UPLOAD_MB=2000`,
   далі `systemctl --user restart ytbot`

Увага: при переході на локальний сервер Telegram вимагає `logOut` бота з хмарного
сервера один раз:
`curl "https://api.telegram.org/bot<TOKEN>/logOut"` — і тільки після цього
локальний сервер прийме токен.

Кеш локального сервера лежить у `~/ytbot/tgapi-data` і росте — час від часу чистити.
